Audit trail for AI-written code

git blame tells you who.
Whyline tells you why.

Whyline records what AI agents change in your codebase: the prompt, the files, the commit and the agent. Run whyline blame on a line to see why it exists, or search and export the timeline for your team.

What gets recorded

Every event ties a change to the reason for it. What each source captures is listed here, and nothing more.

Prompts

The text of each prompt you submit in Claude Code. You can turn text capture off; the fact that a prompt happened is still recorded.

Edits

Each file Claude Code changes with Edit, Write, MultiEdit or NotebookEdit, with the file path.

Commits

For any agent or person: the commit hash, author email, message and changed files, plus the agent when the commit message names one.

Every event also has a timestamp, an agent name and a kind (prompt, edit or commit). See all event fields.

Which agents are covered

Claude Code has a plugin. Every other agent is recorded when it commits, if its commit message says which agent wrote it.

SourcePromptsEditsCommitsHow
Claude CodeYesYesYesThe Claude Code plugin, plus the git hook for commits
Cursor, Copilot, Codex, Gemini, Aider, Devin, WindsurfNoNoYesThe git hook, when the commit message has a Co-Authored-By: or AI-Agent: trailer naming the agent
Anything else, or no trailerNoNoYes, as agent noneThe git hook

The agent has to write the trailer itself. Whyline reads commit messages; it does not look inside those agents.

How it works

Hooks capture events, a workspace stores them, and you ask why from the terminal or the dashboard.

  1. Capture

    The Claude Code plugin and a git post-commit hook send events to your workspace. They never block the agent or the commit.

  2. Store

    Events live in a workspace behind an API key, on the hosted site or on a server you run yourself.

  3. Ask why

    whyline blame file:line finds the commit behind a line and prints its agent, author and prompt. The dashboard has a searchable timeline and CSV export.
