How it works

  1. Agents work as usual

    Whyline hooks into Claude Code and git. Nobody changes how they code.

  2. Every prompt, edit and commit is recorded

    Tied to files, commit hashes and the developer who ran the agent.

  3. Ask "why is this here?" and get an answer

    On the team timeline, or from the terminal with whyline events.

Install in 60 seconds

  1. Create a workspace and copy your key

    Create workspace

  2. Install the CLI

    pnpm add -g whyline
whyline login --url https://whyline.dev --key wl_...

  3. Connect your agents

    # Claude Code: prompts and every file edit
/plugin marketplace add whyline/whyline
/plugin install whyline@whyline

# Any other agent: every commit, in each repo
whyline init
